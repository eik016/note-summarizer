# 📝 講義ノート要約＆復習クイズアプリ

大学の講義ノートや資料をアップロードするだけで、AIが「要約」「復習クイズ」「質問への回答」を行ってくれるWebアプリです。

以下のリンクから、ブラウザ上で実際にアプリをお試しいただけます。
👉 https://note-summarizer-8nzxeuztjnx5mzoppl6mle.streamlit.app/
---

## 主な機能と特徴

1. **様々な入力対応**
   - テキストの直接入力に加え、PDF・画像（PNG/JPG）・テキストファイル（.txt)のアップロードに対応。
2. **AIによる構造化要約生成**
   - Google Gemini API (`gemini-3.6-flash`) を活用し、「講義概要」「重要キーワード」「箇条書きポイント」の3項目で自動要約。
3. **復習クイズ機能（3択問題×3問）**
   - ユーザーが「復習クイズに挑戦する」ボタンを押したタイミングで、講義内容に沿った3択クイズを自動作成。
   - 画面上のラジオボタンで回答を選択し、即座に「自動採点・正解・詳細な解説」を表示。
4. **Q&A チャット**
   - 資料と要約を保持したまま、AI（ティーチングアシスタント）に追加質問が可能。
5. **サイドバー履歴管理**
   - 過去に作成した要約や質問ログをサイドバーへ自動保持・即時反映。
6. **テキストダウンロード機能**
   - 生成された要約結果とQ&Aのやり取りを一発で `.txt` ファイルとして保存可能。

## 使用技術

- 使用言語: Python 3.12 
- webフレームワーク: Streamlit
- SDK: google-genai (Gemini API / gemini-3.6-flash)
- データ処理: JSON(クイズ構造化出力用）,Pillow(画像）
- バージョン管理・デプロイ: Git 、 GitHub、Streamlit Community Cloud

## 開発で工夫したポイント

- ## 💡 技術的な工夫・こだわり

- **オンデマンド処理によるUX（操作性）の最適化**  
　最初からクイズ生成まで行うとAIの処理待ち時間が長くなるため、要約をまず高速に表示し、クイズはユーザーが「挑戦する」ボタンを押した時だけ生成するオンデマンド設計にしました。

- **JSON構造化出力を用いたUI・自動採点の連携**  
  Gemini APIのプロンプトでJSONフォーマットを指定し、取得したデータをPythonでパース（解析）することで、StreamlitのラジオボタンUIや自動採点・解説表示とスムーズに連動させています。

- **`st.session_state` と `st.rerun()` による状態管理**  
  アプリの画面再描画時にデータが消えるのを防ぐため、セッション状態で要約やチャットログを保持。さらに `st.rerun()` を活用して、新しい要約を作成した瞬間に左側サイドバーの履歴へリアルタイムで同期させています。

1. リポジトリのクローン
```bash
git clone https://github.com/eik016/note-summarizer.git
cd note-summarizer
```
2. 依存ライブラリのインストール
```bash
pip install -r requirements.txt
```
3. 環境変数の設定

`.streamlit/secrets.toml` ファイルを作成し、ご自身のGemini APIキーを設定します。

```toml
GEMINI_API_KEY = "YOUR_API_KEY"
```
4．アプリの起動
```bash
python -m streamlit run app.py
```
